# Documentation Map

Textweft의 문서는 **주제별 정본과 짧은 탐색 경로**로 관리합니다. 문서가 필요하면 가장 가까운 소유자를 선택하고, 같은 계약을 여러 문서에 복제하지 않습니다.

| 영역 | 소유 범위 |
| --- | --- |
| [Goal](goal/README.md) | 제품 목표, 철학, 역할 용어, 언어 기준 |
| [Architecture](architecture/README.md) | 확정된 기술 결정, 계층 경계, 미확정 설계 조사 |
| [Development](development/README.md) | 개발 우선순위, 에이전트 협업, 워크플로, 검증 |
| [Documentation](documentation/README.md) | 문서 소유권, 작성, 메타데이터, 인덱스 |
| [Tools](tools/README.md) | 개발 도구와 Rulesync의 설치·운영 진입점 |

넓은 주제 탐색은 [INDEX.tsv](INDEX.tsv)의 `path`와 `description`을 사용합니다. 이미 소유자를 알면 직접 링크합니다. 구현 사실은 문서 요약보다 코드·테스트·[README](../README.md)를 우선합니다.
