# Language

**기본 언어는 한국어입니다.** 사람이 읽는 신규 문서·설명·에이전트 지침·리뷰·이슈/PR 논의·커밋 메시지 및 메타데이터 값에 적용합니다. 기술 용어·고유명사는 영어가 더 명확할 때 원어를 사용합니다.

## English Exceptions

다음은 영어로 작성하거나 기존 영문 표기를 유지합니다.

- Markdown의 H1–H3 제목. H4 이하의 제목과 본문은 한국어를 기본으로 합니다.
- 코드 식별자, API·스키마 필드명, 파일명, 경로, 명령어, 프로토콜·직렬화 키 및 기계가 해석하는 문자열.
- Conventional Commits의 `feat:`, `fix:`, `docs:` 같은 접두사와 기타 도구가 요구하는 형식.
- 향후 등록되는 Rule·Skill 등 에이전트 자산의 **검색·라우팅용 frontmatter `description`**. 사람이 읽는 일반 문서의 `description`은 한국어를 사용합니다.

## Content and Exceptions

- 게임 내 대사·서사·선택지 등 **플레이어에게 표시되는 콘텐츠**의 언어는 각 게임 또는 콘텐츠의 요구사항에 따릅니다. 저장소 기본 언어를 게임 콘텐츠에 강제하지 않습니다.
- 코드 예제, 테스트 픽스처, 외부 원문·인용, 라이선스 텍스트, 자동 생성물은 정확성·호환성에 필요한 원형을 유지합니다.
- 라이브러리·플랫폼·도구 규격이나 명시적으로 합의된 대상 독자·현지화 요구가 있다면 해당 범위에서 우선합니다.
- **기존 영어 문서를 일괄 번역하지 않습니다.** 신규 문서와 실질적인 개정 시 점진적으로 적용하며, 주변의 안정된 기술 표기와 링크는 유지합니다.

## Ownership

이 파일은 언어 및 표기 규칙만 소유합니다. 프로젝트의 목표는 [GOAL.md](GOAL.md), 실행·권한 계약은 [AGENTS.md](../AGENTS.md), 현재 구현 사실은 [README.md](../README.md)와 코드·테스트를 따릅니다.
