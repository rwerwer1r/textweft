# Glossary

| 용어 | 정의 |
| --- | --- |
| **프레임워크 개발자** | Textweft 프레임워크 자체를 개발·유지보수하는 개발자 |

| **게임 사용자 / 게임 플레이어** | Textweft 프레임워크로 제작된 게임을 플레이하는 사람 |
