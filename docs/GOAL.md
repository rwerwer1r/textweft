# Project Goal

**Textweft는 창작자가 AI와 협업해 자신만의 웹 게임을 만들 수 있도록 돕는 게임 제작 프레임워크다.**

## Vision

게임을 만들고 싶은 사람이 엔진 내부의 복잡성보다 이야기, 규칙, 표현하고 싶은 경험에 집중할 수 있는 환경을 지향한다. 주 사용자는 자연어로 의도를 설명하고 AI 코딩 도구와 함께 게임을 만드는 바이브코더다. Textweft는 특정 게임 한 편이나 장르 전용 도구가 아니라 서로 다른 게임에 재사용할 수 있는 기반을 목표로 한다.

## Initial Focus

우선 **텍스트와 정적 이미지로 구성된 웹 게임**에 집중한다. 간단한 미연시를 만들 수 있는 수준은 목표를 확인하는 좋은 사례지만 프레임워크 자체를 미연시 전용으로 만들지는 않는다.

## Long-term Direction

장기적으로 더 다양한 미디어, 2D 애니메이션, 게임별 선택적 MOD 등으로 창작의 폭을 넓힐 수 있기를 지향한다. 이러한 가능성은 열어두되 지금은 구체화하지 않는다. 개발 철학은 [Principles](PRINCIPLES.md)에서 다룬다.
