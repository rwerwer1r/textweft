# Vibe Coding Workflow

Textweft는 바이브코더용 게임 제작 프레임워크입니다. 게임 개발자는 자연어로 목표·제약·피드백을 전달하고, Agent는 이를 게임 정의·테스트·코드·예제로 구체화합니다.

## Responsibilities

- **프레임워크 개발자:** 자연어로 목표·우선순위·제약·피드백을 제시하고 중요한 제품 결정을 승인합니다.
- **AI:** 의도를 관찰 가능한 수용 조건으로 구체화하고 최소 구현·테스트·예제·문서·자체 리뷰를 주도합니다.
- **Routine Loop와 권한:** [Agent-driven Development](agent-driven-development.md)와 [AGENTS.md](../../../AGENTS.md)가 소유합니다.

## Vibe-coder Experience

1. 자연어 의도 → 게임 정의·에셋 참조·선택적 확장 → 실행 → 오류 수정이 가능한가?
2. 공개 타입·문서·예제·오류만으로 AI와 게임 개발자가 장면·선택·상태·정적 이미지 참조를 이해·수정할 수 있는가?
3. 게임별 특수 규칙을 코어에 누적하지 않고 공개 계약으로 확장할 수 있는가?

관련 변경은 구체적 시나리오와 실제 관찰 결과로 검증합니다. AI 코딩 도구 사용성을 실측하지 않았다면 명시합니다. 예제 게임은 프레임워크 검증용이지 제품이 아닙니다.
