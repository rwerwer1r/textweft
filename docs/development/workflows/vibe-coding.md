# Vibe Coding Workflow

Textweft는 **바이브코더용 게임 제작 프레임워크**이며 개발도 AI 주도 바이브코딩으로 진행합니다. 역할은 [GLOSSARY](../../GLOSSARY.md), 제품 목표는 [GOAL](../../GOAL.md)를 따릅니다.

개발 주체와 책임 분리는 [Agent-driven Development](agent-driven-development.md)를 따릅니다.

## Responsibilities

- **프레임워크 개발자:** 자연어로 목표·제약·우선순위·피드백을 제시하고 중요한 제품 결정을 승인합니다. 세부 코드 설계를 매번 지정하지 않습니다.
- **AI:** 의도를 관찰 가능한 수용 조건으로 구체화하고 최소 구현·테스트·예제·문서·자체 리뷰·PR을 주도합니다. 검증하지 않은 코드를 수용하지 않습니다.
- 일상 절차는 [Routine Loop](routine-loop.md), 권한·승인은 [AGENTS.md](../../../AGENTS.md)가 소유합니다. 여기서 중복 루프를 정의하지 않습니다.

## Vibe-Coder Experience

공개 API·저작 경험을 변경할 때 확인합니다.

1. **자연어 → 게임 정의·에셋 참조·선택적 확장 → 실행 → 오류 수정**이 가능한가?
2. 공개 타입·문서·예제·오류만으로 AI와 게임 개발자가 장면·선택·상태·정적 이미지 참조를 이해·수정할 수 있는가?
3. 게임별 특수 규칙을 코어에 누적하지 않고 공개 계약의 범위에서 확장할 수 있는가?

관련 변경은 구체적 시나리오와 **실제 관찰한** 결과로 검증합니다. AI 코딩 도구 사용성을 실측하지 않았다면 명시합니다. 예제 게임은 프레임워크 검증용이지 제품이 아닙니다.
